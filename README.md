# Ave Algpeuse tutvustus

Lihtne eestikeelne tutvustusleht, mis räägib Ave Algpeusist, tema huvidest ja GitHubi profiilist.

## Failid

- `index.html` – veebilehe avaleht. Kohalik fail `tutvustus.html` tuleb enne avaldamist ümber nimetada `index.html`-iks.
- `ave-algpeus.png` – lehel kasutatav foto.

## Avaldamine GitHub Pagesiga

1. Laadi `index.html`, `ave-algpeus.png` ja see `README.md` üles hoidla `avealgpeus/tutvustus` juurkausta.
2. Ava hoidlas **Settings → Pages**.
3. Vali **Deploy from a branch**, haruks `main` ja kaustaks `/(root)`, siis salvesta.
4. Leht avaldatakse aadressil <https://avealgpeus.github.io/tutvustus/>.

Hoidla: <https://github.com/avealgpeus/tutvustus>

GitHub Pagesi seadistamise juhend: <https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>
